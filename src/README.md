# Controle de Produção Multiway Infra

## Descrição

Sistema desenvolvido para o Projeto Integrado do curso de Análise e Desenvolvimento de Sistemas da UNIFEOB.

A solução tem como objetivo auxiliar no controle do processo produtivo da empresa Multiway Infra, permitindo o cadastro de peças, atualização de status de produção e acompanhamento dos responsáveis pelas atividades.

## Funcionalidades

- Cadastro de peças
- Consulta de peças
- Atualização de status
- Controle de responsáveis
- Listagem das peças cadastradas
